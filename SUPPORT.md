# Support

Mission Control is community-supported and currently pre-1.0.

## Get help

1. Review the [public setup guide](docs/public/setup.md) and existing
   documentation.
2. Search open and closed issues.
3. Open a bug report with a minimal synthetic reproduction if the problem is
   reproducible.

Feature proposals belong in the feature request form. General operational
questions may use GitHub Discussions when discussions are enabled.

## Keep reports safe

Never post tokens, environment files, database contents, production logs,
connector payloads, private URLs, or personal information. Redact identifiers
and reproduce problems with synthetic data.

Security vulnerabilities must use the private process in
[SECURITY.md](SECURITY.md). Security reports opened as public issues may be
removed to reduce exposure.

## Service level

There is no guaranteed response or resolution time for community support.
Security reports follow the response target in `SECURITY.md`. Support applies to
the latest release and default branch as described in the
[compatibility policy](docs/governance/compatibility.md).
