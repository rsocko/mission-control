# Store Assets

Assets required for Chrome Web Store and Edge Add-ons submissions.

## Required Files

| File | Dimensions | Used By |
|------|-----------|---------|
| `icon-128.png` | 128×128 | Both stores (already in `../icons/`) |
| `screenshot-1.png` | 1280×800 or 640×400 | Both stores |
| `screenshot-2.png` | 1280×800 or 640×400 | Both stores |
| `promo-small.png` | 440×280 | Chrome Web Store (optional) |
| `promo-marquee.png` | 1400×560 | Chrome Web Store (optional) |

## Guidelines

- Screenshots should show the extension in action (popup open, capture feedback, etc.)
- Use a clean browser window with no other extensions visible
- Show real content being captured (use mission-control.example as the target)
- PNG format, no transparency needed for screenshots
