One action, typed destinations

Source connectors tell Mission Control where a task came from. Execution destinations advertise what work they can accept and the fields they require. A task can use source context to prefill a destination, but those are separate capabilities.

Where “Delegate” appears

Task detail header

Primary entry for deliberate single-task delegation. Opens the full destination and review flow.

always visible*
Task row context menu

Fast expert entry. Opens the same flow with the task already bound.

secondary
Bulk action bar

Available for two or more selected tasks. Eligibility is calculated before review.

selection
Assignment status section

After dispatch, the action becomes status, progress, outputs, retry, and truthful cancellation limits.

Generic front door, not generic payload

Mission Control owns selection, policy, preview, confirmation, and durable status. Each destination owns its typed configuration.

Availability is configuration-driven

Show only enabled, compatible destinations. Explain setup or policy blockers without offering silent fallback.

Bulk is explicit fan-out

Default to one durable assignment per task. Provider-specific grouping is a separate, reviewed option—not an accidental merge.
