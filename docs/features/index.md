# Feature Guide

This section documents each major view in Mission Control — what it does, how it works, and how the pieces connect.

## Views at a Glance

| View | Route | Purpose |
|------|-------|---------|
| [Dashboard](./dashboard.md) | `/` | Unified task list with filters, grouping, KPIs, and widgets |
| [My Day](./my-day.md) | `/today` | Focused daily planner with scheduling and AI suggestions |
| [Triage](./triage.md) | `/triage` | Review and route incoming content from capture sources |
| [Kanban](./kanban.md) | `/kanban` | Visual drag-and-drop board with customizable columns |
| [Projects](./projects.md) | `/projects` | Portfolio hub with progress tracking and health indicators |
| [Goals & Ideas](./goals.md) | `/goals` | Tag-based capture and development of aspirations |
| [Timeline](./timeline.md) | `/timeline` | Calendar view of tasks by due date |
| [Routines](./routines.md) | `/routines` | Habit tracking with streaks, heatmaps, and cadence insights |
| [Insights](./insights.md) | `/insights` | Analytics dashboard with trends, charts, and AI observations |
| [AI Assistant](./ai-assistant.md) | `/ai` | Natural language chat, background agents, and insights |
| [Document Intake](./document-intake.md) | `/intake` | Parse documents into projects with issues, phases, and tags |

## Cross-Cutting Capabilities

These capabilities are available across multiple views:

- **[Quick Add](./quick-add.md)** — Global task creation (`N` or `Ctrl+K`) with shared NLP parsing and context-aware defaults
- **Task Detail Panel** — Slide-over panel for editing any task (available on Dashboard, My Day, Kanban)
- **Bulk Actions** — Multi-select with batch operations (complete, move, tag, delete)
- **Source Indicators** — Colored icons showing data provenance on every task
- **Keyboard Shortcuts** — View-specific and global shortcuts for power users
- **Sync Stream** — Real-time sync progress indicator with automatic data refresh
