# Usage Guide

A walkthrough of Mission Control's main features and UI areas.

:::note[Screenshots coming soon]
This guide will be updated with screenshots as the UI stabilizes. For interactive mockups, see the [Mockups section](../mockups/).
:::

## Dashboard

The main dashboard shows a high-level view of your day:

- **KPI Cards** — Task counts, overdue items, upcoming deadlines
- **Today's Focus** — AI-suggested priority items
- **Recent Activity** — Latest synced changes across all sources

## Unified Task List

All tasks from connected sources in a single filterable view:

- **Filters** — By source, status, priority, tags, date range
- **Sort** — By due date, priority, smart score, source
- **Sub-tasks** — Expandable hierarchy for complex tasks
- **Quick actions** — Complete, snooze, move, and tag inline

## Triage Queue

Review and route incoming content from various capture sources:

- **Sources** — GitHub Stars, Reddit Saved, YouTube Watch Later, iOS Shortcuts, browser extension
- **Actions** — Route to tasks, projects, bookmarks, or dismiss
- **Smart scoring** — AI-ranked relevance and urgency
- **Batch operations** — Select multiple items for bulk routing

## My Day

A focused daily planner:

- **Auto-populated** from due dates and calendar events
- **Manual additions** — Drag or add specific tasks
- **Time blocking** — Optional time slot assignment
- **Smart suggestions** — AI recommends what to tackle today

## Kanban Board

Visual task organization with drag-and-drop columns:

- **Customizable columns** — Map to any status workflow
- **Source badges** — See which system each task comes from
- **Column limits** — Optional WIP limits per column

## AI Assistant

Natural language interface for task management:

- **Queries** — "What's overdue?", "Show me GitHub tasks for this week"
- **Actions** — "Create a task to...", "Move this to next week"
- **Summaries** — "Give me a weekly summary"
- **Smart categorization** — Auto-tag and prioritize new items

## Settings

Configure connectors, sync schedules, and preferences:

- **Connectors** — Enable/disable and configure each integration
- **Sync Schedule** — Set polling intervals per connector
- **AI Configuration** — Model selection, provider settings
- **Triage Sources** — Auto-sync toggle and intervals
