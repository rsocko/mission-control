# Naming and Trademark Guidance

No trademark license is granted by the source-code repository or by any future
software license.

You may use the project name factually to describe compatibility or an
unmodified copy. Do not imply endorsement, official status, or affiliation.
Modified distributions should use a distinct name and branding and should state
that they are derived from Mission Control.

Third-party names and logos belong to their respective owners. Their appearance
in documentation describes interoperability and does not imply endorsement.

Project naming, logos, and asset rights require legal/IP approval before public
release. Questions about branded distribution should be raised with the
repository owner before publication.
