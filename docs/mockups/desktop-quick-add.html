Authentication

Pair, do not paste keys

Desktop requests a short code, opens MC's approval page once, then stores a revocable device token in Windows Credential Manager via a Tauri secure-storage plugin.

Reliability

Idempotent offline outbox

Queue captures locally when MC is unreachable. Retry with the same idempotency key; show pending count on the tray icon and never duplicate a task.

Compatibility

Server capability handshake

GET /api/v1/desktop/capabilities returns feature flags, destinations, parser version, and minimum supported client version.

Current gap: the existing POST /api/tasks accepts already-parsed fields, while significant Quick Add behavior lives in the browser component. The MVP should first extract a shared server-side Quick Add service and protect desktop mutations with scoped device tokens. The existing general API key is useful for automation but too broad and awkward for consumer pairing.

MVP success criteria

Speed

<150 ms summon

Warm hotkey-to-focused-input latency on a typical Windows 11 machine; submit feedback begins within 100 ms.

Reliability

No lost captures

Every accepted input is either confirmed by MC or visibly retained in the local outbox until resolved.

Habit

Keyboard-only loop

Hotkey, type, Enter, continue working. The website remains closed unless the user chooses Open.

Product decisions to validate

The design has defaults, but these choices materially affect the build.

Primary platform

Start Windows-first while keeping the Tauri core portable. Native Windows App SDK would improve deep shell integration but increase cost and reduce portability.

Recommend Windows + Tauri
Default hotkey

Ctrl+Alt+Space is memorable but can conflict with input methods. Detect conflicts during onboarding and require the user to confirm or rebind.

Confirm in onboarding
Close behavior

On successful single capture: close immediately and toast. With Ctrl+Enter or meeting mode: clear and stay open for rapid entry.

Recommend dual behavior
Offline semantics

Queue locally and notify "Saved offline" rather than rejecting. Let users inspect and retry pending captures from the tray.

Recommend queue
Hover surface

Do not enable an edge target by default; persistent screen chrome can be distracting. Offer it as an opt-in mouse-first mode after MVP.

Defer from MVP
Windows Widget

Useful for My Day visibility, but Windows widget packaging/provider requirements are heavier than a floating window and are not ideal for rapid text focus.

Advanced, not core
Scope of v1

Capture tasks only. URL/content capture already has browser and iOS clients; unify them under a common capture API later rather than bloating the first desktop loop.

Recommend task-first
