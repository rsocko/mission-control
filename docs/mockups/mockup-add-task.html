📐 Design Notes
Quick bar is always visible at the top of Dashboard, My Day, and Kanban pages.
Default destination is configurable in Settings (e.g., "always default to Personal Todo").
Last used destination is remembered and pre-selected next time.
Keyboard-first: N opens, type + Enter saves, Tab expands to full, Esc cancels.
Smart parse runs live as you type — shows chips below the bar in real-time.
Post-save toast confirms "✓ Added to Todo · Personal" with an Undo link.
Source-adaptive form: GitHub gets markdown + labels. Todo gets reminders + steps. Custom DB gets custom fields.
