Mission Control / Horizon concept

Planning horizon state icons

Four broad planning intents—not due-date promises. This study compares compact horizon codes, a coherent signal metaphor, and literal icons from Lucide, Phosphor, and Material Design Icons.

Recommended direction

Use H1 / H2 / H3 / ∞ as compact row badges and as markers beside the full labels in menus. It is distinctive, compact, and preserves “Someday” as intentionally unbounded. Code-only row badges expose the full label in a tooltip.
