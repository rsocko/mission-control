Design Notes

Relationship to Today View

All Tasks uses the same task row pattern (priority dot, truncated title, metadata subtitle) as Today, but adds source-section headers with collapsible groups. Today remains the curated "what's on my plate now" view; All Tasks is the complete inventory.

Grouping

Default grouping is by Source (per #1578). Users can pivot to Priority, Project, Due Date, or Tag via the inline group-by bar or the full filter sheet. The "None (flat)" option gives a single sorted list.

Filtering

Source filter chips provide one-tap access. The bottom-sheet filter panel allows toggling sources on/off, filtering by status (active/completed/deferred), and choosing sort order within groups. Active filters show a dismissible banner.

Collapsed Groups

Groups beyond the first two are collapsed by default to keep the initial view scannable. Collapsed groups show source icon + count. Tap to expand. Expand/collapse state is persisted per session.

Navigation

Accessible from the hamburger menu drawer under "Views" section. Not in the tab bar (that stays focused on daily workflow: Today, Triage, Capture, Sort, Houston).
