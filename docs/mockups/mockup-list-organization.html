How grouping works

Groups organize Mission Control navigation. They do not move or merge anything in the source system.

A group can combine lists from multiple sources around one real-world context.
Each source still has its own section in navigation, so provenance stays visible.
Sources without native groups can still participate in Mission Control groups.
This is list identity, not grouping. Display names, icons, visibility, and context appearance live together here so the grouping screen can stay focused.
