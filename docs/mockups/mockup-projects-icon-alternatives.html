Kanban Conflict

If Projects adopts a grid, table, or modular metaphor, these pairings keep Kanban visually distinct so the two destinations do not compete in the rail.

GitHub-native split

Use the Octicon Project mark for Projects, then keep Kanban literal with a board icon. This most closely mirrors GitHub's own distinction.
