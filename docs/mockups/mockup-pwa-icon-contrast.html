Can users choose the black or white installed icon?

Not reliably after installation. Mission Control can offer black/white choices for the in-app logo and browser favicon, but Edge/Chromium selects the Windows icon from the manifest and provides no runtime icon-switching API. A per-user installed-icon choice would need to be made before installation through a user-specific manifest/icon URL, and changing it later may still require reinstalling the PWA. See MDN app icons and Chrome manifest updates.
