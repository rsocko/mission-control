Design Decisions — Unified Model (Option A)

  • Pills row removed: The token input IS the single place where active filters are displayed. No separate pills row above.
  • Sidebar = shortcut panel: Clicking a sidebar item adds/removes a token in the unified input. Sidebar shows active state (filled dot) synced with tokens.
  • Bidirectional sync: Removing a token from the input deselects it in the sidebar. Adding via sidebar appears in the input.
  • Negation (advanced): Only creatable via typing -tag:X or the Phase 3 builder. Sidebar shows negated items with strikethrough + ⊘ indicator but doesn't create them.
  • Collapsed sidebar: When sidebar is collapsed to icon rail, the token input is self-describing — all active filters are visible as pills.
  • Clear all: Button in the input clears all tokens AND deselects everything in the sidebar.
  • Save as view: Saves the full token set (including negations and free text) as a named view.
Migration note: In Phase 1 (current), the pills row and keyword input coexist. In Phase 2, the pills row merges into the token input. The sidebar continues to work as before but now syncs with tokens instead of a separate pill display.
