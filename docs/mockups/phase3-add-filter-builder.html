Design Decisions — Phase 3 (Unified Model)

  • "+ Add Filter" button: Always visible next to the token input. Opens category dropdown → value picker. Selected values become tokens.
  • Negation via builder: Value picker has an "Exclude" mode toggle. When active, selections produce -tag:X tokens (red pills). Sidebar reflects negation with ⊘ + strikethrough but cannot create negations itself.
  • Operators (due date, effort): Value picker offers preset operator options (before/after/overdue/week). Advanced users can also type due:<2026-08-01 directly.
  • Sidebar remains a shortcut: Only handles simple include/exclude display. Clicks add include tokens. No 3-state interaction — keeps it simple.
  • Token removal: Backspace in empty input removes last token. × on token removes it. Both deselect in sidebar.
  • Keyboard flow: / focuses input → type token or free text → Tab accepts autocomplete → Enter applies → Escape closes dropdown.
  • Save as view: 💾 button saves all active tokens (including negations, operators, free text) as a reusable named view.
✓ Unified model complete: One token input is the single source of truth for all active filters. Sidebar = discovery shortcut. Builder = guided creation. Typing = power users. All three entry points converge on the same token set.
